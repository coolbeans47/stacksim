# Project Instructions

## Testing

- Do not run the full regression test suite unless the user explicitly asks for it.
- Keep test runs focused on the code being changed. Run only the existing tests that are relevant to the affected behavior, along with any new or updated tests for that behavior.

## Compatibility

- All code and tests must work on Linux, macOS, and Windows.
- Support Node.js 22 and later.
- Avoid platform-specific paths, shell syntax, commands, and APIs unless they are implemented with a cross-platform alternative or appropriately guarded.
